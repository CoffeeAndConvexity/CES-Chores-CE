# Historical experiments

These files preserve earlier research work and are not current entry points:

- `legacy/`: earlier scripts, results, and figures, previously stored in `old files/`.
- `bidding-results/`: parameter-specific bidding results previously stored in the repository root.
- `figures/`: earlier figure versions that differ from the canonical figures in `../figures/`.

Historical scripts retain their original path assumptions. Use the maintained scripts in `../code/` for new experiments. The initial repository commit preserves the original layout.
